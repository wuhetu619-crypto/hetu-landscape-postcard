## 单图实测

[合成原片](../examples/synthetic-source.png) · [成品](../examples/synthetic-postcard.png) · [原片生成提示词](../examples/source-prompt.txt) · [明信片编辑提示词](../examples/postcard-prompt.txt)

设定：森林溪流，暖米纸、灰黑印墨与苔绿点色，摄影为主，右侧纸面延展，小字为 `where the stream slows`。主体是左侧树、前景大石与向中部延伸的溪流。所有素材为 AI 测试生成，不代表真实地点。

| 视觉检查 | 观察 |
| --- | --- |
| 主体与空间 | 左侧大树、前景两块主要圆石、溪流方向与山谷关系保留；枝条、岩石纹理和局部尺度有生成性变化 |
| 摄影与版画 | 左下主体仍是摄影，右上山体与右侧树冠、水纹成为限色印痕 |
| 跨界 | 树冠和水纹有清楚呼应；山脊交界不是几何精确连续，后续还可改善 |
| 撕纸 | 长裂口与局部毛边自然，无规则锯齿或厚重阴影 |
| 材质颜色 | 米纸、暖灰墨、绿色印痕协调；纸纤维略明显但主体仍清楚 |
| 文案 | 英文短句正确、位置克制，没有水印或大标题 |
| 输出 | 1086 × 1448，3:4，正常打开 |

该例达到风格目的，但不能宣称原片像素无损、结构完全精确或所有地标都能可靠保真。本次没有为追求更高主观分数反复重生成。

## 八条情景静态审查

以下是对规则覆盖的审查，不是八次实际生成。

| 请求情景 | 规则要求的处理 |
| --- | --- |
| 单张森林照，无其他要求 | 自动选预设并出一张，不强制问卷 |
| 横向古城照，要求保留全部城门 | 调整摄影窗口/比例，保留地标轮廓 |
| 两只鸟，无字 | 数量列入保留项，禁添第三只与任何字 |
| 中文指定短句 | 精确原文，小号宋体气质，不擅改文字 |
| 五张旅行照同系列 | 锁纸/墨/字形/位置，允许原片点色变化 |
| 只改已有成品的文字 | 保持其余维度，若重生成漂移须说明 |
| 公共包缺参考图 | 文字规则继续，不虚称已查看样图 |
| 100 × 150 mm 印刷 | 按实际像素计算 PPI，按印厂要求处理出血，不声称已打样 |
