# 质量检查与修正

检查两层证据：程序可读的文件事实，以及查看图片得出的视觉判断。二者不能互相替代。

## 先查硬性缺陷

存在以下任一项，不标为“完成且通过”：

- 未使用实际待编辑原片，或把风格样图当作原片。
- 主体身份、数量、关键轮廓或场景关系明显错误。
- 没有摄影 + 撕纸 + 暖纸 + 同景版画中的任一项。
- 无字要求被忽略、指定文字拼错、水印或参考物体混入。
- 输出损坏、无法打开、实际比例不符合约定且未说明。

## 七项视觉评价（每项 0–2）

这是人工检查量表，不是模型质量的客观量化。每项必须写一句可观察证据，禁止只填分数。

| 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 原片保真 | 主体缺失/改错 | 可辨认但局部漂移 | 主体与重要关系保持 |
| 跨界连续 | 无同景关系 | 有呼应但断裂 | 至少一条主要结构明确接续 |
| 撕纸可信 | 矩形框/锯齿/纸雕 | 基本自然但单调 | 大轮廓自然、细纤维有变化 |
| 印刷语言 | 灰度照片/普通插画 | 有断墨但工艺混乱 | 工艺一致、简化有层次 |
| 色彩明度 | 发脏/堵黑/点色抢眼 | 大体协调 | 纸墨点色各司其职、主体清楚 |
| 构图留白 | 主体被切/拥挤 | 结构可用 | 主次明确、空纸能呼吸 |
| 文字符合 | 错字/违背无字 | 正确但尺度欠佳 | 正确、克制、清晰；无字请求完全无字 |

建议完成线：硬性缺陷为零，总分至少 11/14，原片保真必须 2 分，其余不得 0 分。这是工作标准，不应对用户宣称为独立评测得分。

## 有界修正

1. 找影响最大的一个缺陷，重申主体和已通过项，只修改相关维度。
2. 保存新版本，再对照原片与前版查看。
3. 同一问题最多两次修正，失败则说明局限，不通过编造检查结果结束。

| 缺陷 | 修正方向 |
| --- | --- |
| 只有照片纸框 | 指定一条原片结构跨过裂口变成版画 |
| 整图变插画 | 恢复摄影区真实纹理，仅纸面限色 |
| 版画像灰度照片 | 减少色阶，加入明确刻线/形块/断墨 |
| 边缘不自然 | 减少规则锯齿与投影，增细纤维差异 |
| 主体被裁 | 改窗口或比例，减少装饰占比 |
| 点色过多 | 版画只保留一种点色，摄影自然颜色不算违规 |
| 小字错误 | 精确文字定向编辑；无字版须符合用户要求 |
| 过度做旧 | 去污渍与粗噪点，保留微纤维 |

## 技术检查

运行 `python3 scripts/check_image.py <成品> --aspect 3:4` 可读取 PNG/JPEG/WebP 宽高并报告比例差。它不判断视觉风格，不保证图像可完整解码；仍要实际查看。

印刷用途额外核对实际像素与拟印尺寸对应的 PPI。没有印厂色彩配置和实物打样，不宣称已通过印刷色彩验证。
