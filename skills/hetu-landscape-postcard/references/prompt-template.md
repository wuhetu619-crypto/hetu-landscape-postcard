# 提示词与执行记录

## 设计记录

生成前先把以下字段保存到 `design.md`，只写与这一张图有关的信息。

- 原片：文件名、实际尺寸、方向；可见事实，不猜地名。
- 原片保留项：主角、轮廓、数量、相对位置、视角、关键文字。
- 风格参考：文件名与角色（style/composition/palette），缺参考时写“文字规则”。
- 方案：12 维选择、所选骨架、摄影主导程度。
- 跨界结构：明确列出 1–3 个来自原片的元素和它们在纸上的去向。
- 文案：准确原文或“无字”；用户指定文案不能改写。
- 输出：目标比例、数字或印刷用途、实际输出待回读。

观察、估计、技术测量分开写。仅视觉估计的面积不能称为程序测得。

## 完整提示词模板

花括号替换为实际内容；不要把所有场景预设塞进一次生成。

```text
Use case: style-transfer
Asset: 一张平面复古明信片正面图，{比例}，不透明暖纸底。
Input roles: 图1为唯一待编辑原片；{图2/图3的具体参考角色，或无图形参考}。
原片事实：{真正可见的景物和空间关系}。
主体保留：{主角、数量、关键轮廓、位置关系、视角与不可裁切区域}。

风格核心：真实摄影经手撕纸边界转译为同景版画，暖纸留白，印刷颗粒与细纤维。
构图：{骨架名与准确空间安排}，{摄影/版画强弱}。
视线先落在{主焦点}，再沿{引导线}进入{纸面延展}，最后到{留白或小字}。
摄影窗口：{宏观边界形状}，局部细纤维不规则变化，只有轻微接触阴影。
跨界接续：{明确的一至三条景物关系：原片哪里 → 撕口哪里 → 纸面哪里}。
版画工艺：{主工艺}；{明确断墨、线条或形块的呈现方式}。
纸张：{纸色与纹理强度}，纸纹统一全图但不糊掉摄影主角。
色彩：{纸、墨、点色各自角色}；摄影保有自然多色，版画限色。
光与明度：{依原片保留时段、光向和层次；必要的轻微调色}。
层次：{前景摄影/过渡/印刷远景强弱}。
情绪：{安静/清朗/轻怀旧}，不为情绪新增天气、季节或剧情。
文字：{逐字短句与字形、位置、大小；或完全无字}。
系列锁定项：{有则列出，没有则省略}。

不添加原片没有的人、动物、船或建筑，不移植参考图的主体、水印、账号或标记。
不把摄影区全画成插画，不做普通旧纸相框、规则锯齿或厚重三维纸雕。
不加未要求的标题、邮票、邮戳、贴纸、胶带、地址栏、签名或桌面样机。
```

## 输入、保存与修正

本地原片和选中的样图先查看后传入。工具接受本地路径时使用绝对路径；数量与参数遵循当前接口。所有输入必须明确角色，原片第一优先。

每张图在出图前保存最终提示词到 `prompts/01-<原片名>-v1.txt`。重试另存 `v2`，实际发送的文本与文件内容一致。提示词可复用，不承诺逐像素复现。

只有图片没有保存路径时遵循内置工具的输出获取方式，不臆造文件名。保存后回读实际宽高，再记录到 `review.md`。文字错误通过图像编辑修正，不能自行用代码盖字。

用户只改字、颜色或点色时，使用当前成品作为编辑目标、原片作为保留依据；明确其余维度不变。若重生成导致较大变化，不能把它说成只改了文字。
