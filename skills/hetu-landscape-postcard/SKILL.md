# 河图·撕纸风景明信片

将照片里的真实世界，经手撕纸边界转译为同景版画。成品是完整平面明信片正面，默认竖版 3:4。同景的摄影细节与印刷痕迹同时存在，是这一风格的辨识点。

## 不变的风格核心

暖米纸、可辨认的原片、不规则纤维撕边、同景版画、克制留白。扩展的是可调维度，不把风格扩展成任意海报、水彩或贴纸拼贴。

- 原片决定场景事实，样图只决定视觉形式。人物、动物、建筑、河道不因套风格而新增、重复或变形。
- 默认一块主要摄影区域，纸面延展 1–3 组有来源的景物结构；原片已有复杂结构时减少装饰。
- 不默认添加邮票、邮戳、地址栏、旅游大标题、胶带、签名或桌面样机。
- 用户明确选择优先于本技能默认值。已提供原片与目标时直接完成，不强制问卷或首次配置。

## 默认值与选择顺序

1. 用户本次的尺寸、文案、保留项和风格要求。
2. 同一组明信片已经确认的设定；后续只改用户要求的部分。
3. 原片的主体、地平线、主要引导线、冷暖与明暗关系。
4. 场景预设；用户提供的新样图优先于技能自带样图。
5. 无其他信息时：3:4、平衡摄影与版画、暖米纸、灰黑印墨、一种原片点色、一处 2–5 词英文小字、安静情绪。

英文短句保持原创、克制，避免臆造地点、天气、日期或旅行经历。中文用小号印刷宋体气质；无字请求不添加任何文字。横图竖裁会损伤主角时优先改横版 4:3 或保留较宽摄影窗口，不牺牲地标去凑比例。

## 执行

1. 查看待编辑原片。没有明确原片时请用户提供，不能擅自把六张成品样图当作新原片。若用户只要提示词或分析，按其请求交付。
2. 写一份简短设计记录：原片事实、保留项、主焦点、主体与纸面位置、1–3 条跨界结构、12 维选择、原片与参考的角色。记录中的判断和测量应分开标识。
3. 从六图图谱选择 1–2 张存在的本地参考并查看。公共仓库不附带六张第三方样图；缺少时直接使用完整文字语法与预设，不声称已看过图片，也不要求用户补齐非必要样图。
4. 每张图在生成前保存完整提示词至本次输出目录的 `prompts/`，从保存文本调用内置图像编辑工具。环境有 `imagegen` 技能时遵循它；使用实际原片路径，明确每张输入的角色。使用当前工具实际接口，不照抄其他平台的 CLI 标志。
5. 默认内置图片编辑、不透明背景。用户要求出图时交付图像，不用 SVG、HTML 或文本冒充。工具不可用则说明，未经选择不切换外部付费服务。
6. 查看输出，与原片并排核对；按质量检查记录可观察证据。技术尺寸可运行 `scripts/check_image.py`，它只读文件头，不能代替视觉检查。
7. 有缺陷则保存新提示词与新版本，针对一个问题修改，保留主角与已确认设定。同一缺陷最多两次定向修正；仍失败则交付最佳版并说明，不把失败项标成通过。
8. 保存成图、最终提示词、设计记录、实际尺寸与检查结果。回复展示成图和链接，明确验证范围。

本次输入是图片并不授权上传它到 GitHub 或其他公开位置。这个技能的生成流程不自动发布或修改自身。

## 输出与边界

未指定时输出到当前工作目录的 `output/postcards/<原片名>-<时间>/`，避免覆盖。系列、印刷等按需读取相应参考。

生成式编辑不能承诺原片像素完全不变。用户要求严格保留像素时先说明本路径的局限，不能悄悄重画后声称无损。细小文字错误用图像编辑或重生成修正；不要自行用代码盖字。

## 调用示例

- “用河图明信片处理这张照片，保留那两只鸟，无字。”
- “这张古镇照用赭橙、横版，文字是‘沿街慢走’。”
- “这五张做同系列，纸底、墨色和文字位置统一。”
- “同一张图给我摄影更强、留白更多两版。”
